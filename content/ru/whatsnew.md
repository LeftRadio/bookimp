
## Bookimp 1.1.2 — список изменений
<br>

#### Аудиодвижок и воспроизведение
- Новая архитектура аудиодвижка с поддержкой нескольких playback backends.
- Добавлен новый backend на базе BASS.
- Переработан внутренний аудиотракт и унифицирована RT-обработка звука.
- Улучшена совместимость и внутренняя организация VST-обработки.
- Доработано переключение между треками и разными типами источников.
- Улучшена обработка перемотки и переходов при воспроизведении, снижено количество нежелательных хвостов и артефактов.
<br>

#### Онлайн-воспроизведение и кеширование
- Полностью обновлена система онлайн-воспроизведения и сетевого кеширования.
- Ускорен старт воспроизведения онлайн-файлов.
- Улучшена загрузка обложек и метаданных для сетевых источников.
- Добавлены и улучшены настройки интернет-кеша.
<br>

#### Настройки, сборка и установщик
- Обновлено меню аудиоустройств, playback backends и связанных параметров.
- Обновлены сборка и установщик для новой аудиоархитектуры и зависимостей.
<br>

## Bookimp 1.0.6 — список изменений
<br>

#### Интернет-аудио и кеширование
- Добавлено кеширование онлайн-аудиофайлов с поддержкой частично загруженных областей.
- Ускорен запуск онлайн-MP3 и переход между главами.
- Улучшена перемотка в ещё не загруженные участки MP3 и OGG.
- Добавлена предварительная загрузка начала следующей онлайн-главы.
- Оригинальные многоканальные файлы сохраняются без преобразования.
- Плеер корректно работает с серверами без поддержки HTTP Range.
- Полностью загруженные интернет-файлы воспроизводятся как локальные.
- Загруженные данные повторно используются при скачивании книги из библиотеки СВиД.
- Добавлены настройки максимального размера и срока хранения кеша.
- Добавлена очистка всего аудиокеша и кеша отдельных плейлистов.
<br>

#### Интерфейс
- Волна интернет-файла теперь строится постепенно по мере кеширования.
- На волне отображается прогресс загрузки онлайн-файла.
- Убрана искусственная волна-заглушка для интернет-источников.
- Исправлено появление старой волны и информации при переключении между файлами.
- Исправлено отображение статуса буферизации при запуске и перемотке.
- Для файлов без поддержки HTTP Range корректно отображаются позиция и длительность воспроизведения.
- В мини-плеер добавлены кнопки скрытия, открытия основного окна и закрытия приложения.
<br>

#### Метаданные, плейлисты и обложки
- Ускорено получение метаданных и длительности интернет-файлов.
- Увеличен тайм-аут чтения метаданных для медленных серверов.
- Исправлено повторное сканирование ранее добавленных интернет-файлов.
- Онлайн источники с временно неизвестной длительностью больше не определяются как радио.
- Обложки теперь переносятся при экспорте и импорте плейлистов M3U, M3U8, PLS, XSPF и CUE.
- Полный экспорт плейлистов также включает обложки и позволяет восстановить их после чистой переустановки.
- Сохранена совместимость с файлами экспорта предыдущих версий.
<br>

#### Обновление приложения
- Добавлена встроенная проверка наличия новой версии.
- Установщик можно скачать непосредственно из приложения.
- Перед запуском установки проверяется контрольная сумма SHA-256 загруженного файла.
- Добавлена возможность пропустить предложенную версию обновления.
- Обычное обновление сохраняет плейлисты, закладки, настройки, пресеты, обложки и кеш.
- В установщик добавлен необязательный режим «Чистая установка» с предупреждением об удалении пользовательских данных.
<br>

#### Исправления
- Исправлен переход на следующую главу после перемотки на текущем онлайн файле.
- Исправлены зависания онлайн-источников на этапе буферизации.
- Исправлены задержки и мерцание статуса «Буферизация...».
- Исправлена работа частично загруженных онлайн-источников.
- Устранена гонка между старым и новым декодером после перемотки.
- Исправлены ошибки отображения волны, таймкода и информации о текущем треке.
- Улучшена стабильность воспроизведения интернет-радио и обычных онлайн-файлов.
<br>

## Что нового (Версия 1.0.5)
<br>

#### Что изменилось:
- Исправлено открытие одиночного файла из Проводника, когда плеер был закрыт. Теперь файл корректно добавляется в плейлист по умолчанию и запускается.
- Исправлена обработка множественного выбора файлов в Проводнике через пункт «Добавить в новый плейлист». Теперь создаётся один новый плейлист для всей выбранной группы файлов, а не отдельный плейлист на каждый файл.
- Исправлено перетаскивание файлов из Проводника в плейлист по умолчанию. Раньше это работало только для обычных плейлистов.
- Улучшено чтение встроенных обложек из метаданных. Теперь обложки корректно отображаются для OGG и связанных сценариев, в том числе при открытии через CUE.
- Исправлена работа закладок в плейлисте по умолчанию после перезапуска приложения. Теперь они корректно находят нужный трек и не становятся недействительными.
<br>

#### Дополнительно:
- Улучшена обработка команд из контекстного меню Windows.
- Исправлены пограничные случаи для плейлиста по умолчанию, из-за которых часть функций работала нестабильно.
<br>

## Что нового (Версия 1.0.2)
<br>

#### Полная пересборка сервиса плейлистов:
- Поддержка больших плейлистов (Для 100к+ треков: Первое добавление - зависит от скорости диска и обьёма метаданных. Сохранение/Загрузка ~1.5сек.)
- Ассинхроное чтение метаданных, треки в плейлисте появляются практически сразу, нет необходимости ждать пока загрузится полностью.
- Чтение метаданных для сетевых источников
- Импорт/Экспорт всех плейлистов в свой бинарный формат
- Открытие/сохранение плейлистов форматов .m3u, .m3u8, .pls, .xspf, .cue
- Быстрая сортировка/поиск (100к+ треков, ~0.8...1сек)
- Отображение плейлистов переведено на модель/отображение, минимизация потребления памяти отображением
- Сохранения путей добавления файлов по каждому плейлисту
- Автоименование плейлистов по метаданным/именам/родительской папке (выбирается автоматически), больше никаких "Playlist X".
- Расширеный автоматический поиск обложек
<br>

#### Оптимизация сервиса закладок, меньше памяти, выше скорость (1к+ закладок)
- Добалена обработка невалидных закладок при отсутствии плейлиста/трека.
<br>

#### Полная пересборка аудиодвижка (FFMpeg + PortAudio + VST2)
- Поддержка воспроизведения ещё большего множества форматов
- Поддержка сетевых источников (перемотка работает только на допускающих это источниках, например для интернет-радио это невозможно)
- добавлен нативный модуль измерения сигнала, больше никаких внешних вычеслений.
- Значительная оптимизация загрузки процессора для всего процесса воспроизведения
- Добавлена возможность сохранять пресеты для VST плагинов
- Аудиопоток теперь исполняется без GIL, практически полный натив на C (Cython)
- Все аудио-процессы исполняются в 32 bit float
- Добавлен ресемплинг (с возможностью отключить)
<br>

#### Добавлен Веб интерфейс для управление плеером по сети
- Встроенный клиент
- Поддержка внешних клиентов (WebSockets, API доступно [Здесь](web-interface/web-api.ru.md))
<br>

#### Добавлен режим работы из трея
- Доступен интерфейс мини-плеера
- Управление из контекстного меню трея
<br>

#### Добавлено меню в контекстное меню проводника для папок/файлов
- Воспроизведение (плейлист "по умолчанию"), Добавление в текущий/новый плейлист
<br>

#### Добавлена онлайн библиотека СВиД
- Добавление в текущий, или новый плейлист любой книги (как онлайн источника)
- Возможность скачать книгу и автоматически добавить в плейлист
<br>
